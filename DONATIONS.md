## Why donate?

- Keep the extension free for everyone.
- Cover hosting and tooling costs (GitHub Actions minutes, domain, store accounts).
- Fund time for new features: usage insights, cross-device sync, schedule-based blocking,
  and more.

## Other ways to help

No money required — these help just as much:

- ⭐ Star the repo on GitHub.
- 🐛 Report bugs and request features via [issues](https://github.com/VASHvic/time-shield/issues).
- 🌍 Contribute translations or code via a [pull request](https://github.com/VASHvic/time-shield/pulls).
- 📢 Share the extension with someone who would benefit from it.
